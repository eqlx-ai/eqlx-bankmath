# Security

This library does arithmetic that people may rely on for money. If you find a calculation that
returns a wrong number for valid input, a rate table entry that is out of date, or a way to make
the MCP server read a file, reach the network, run code or exhaust memory, please do not open a
public issue. Write to research@eqlx.ai or use GitHub's "Report a vulnerability" button on the
Security tab. Never send real customer data. We aim to reply within five working days.
